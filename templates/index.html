Calculator API Docs

CURL Examples

~ $ curl "pedro5532.pythonanywhere.com/api/calculate/add?firstNumber=6&secondNumber=8"
14
~ $ curl "pedro5532.pythonanywhere.com/api/calculate/subtract?firstNumber=9&secondNumber=14"
-5
~ $ curl "pedro5532.pythonanywhere.com/api/calculate/multiply?firstNumber=-3&secondNumber=2"
-6
~ $ curl "pedro5532.pythonanywhere.com/api/calculate/divide?firstNumber=128&secondNumber=16"
8
~ $ curl "pedro5532.pythonanywhere.com/api/calculate/power?firstNumber=2&secondNumber=10"
1024

Endpoints

/api/calculate/add
/api/calculate/subtract
/api/calculate/multiply
/api/calculate/divide
/api/calculate/power

Error codes

200: success
403: forbidden(happens when powering by numbers higher that 1000)
404: bad request(happens when param/params is/are missing or isn't/aren't numbers)
404: not found
422: unprocessable content(happens when dividing by 0)

Required request params

firstNumber
secondNumber
